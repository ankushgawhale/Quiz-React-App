# 🧠 Quiz App (React)

A simple and interactive Quiz Application built using React.  
Users can answer multiple-choice questions, get instant feedback, and view their final score at the end.

---

## 🚀 Features

- 📌 Multiple choice questions
- ✅ Instant correct/wrong answer highlighting
- 📊 Live score tracking
- 🎯 Final result screen with percentage score
- 🔄 Restart quiz option
- 🎨 Clean and responsive UI (Tailwind CSS)

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- React Hooks (`useState`, `useRef`)

## ▶️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/Quiz-React-App.git
2. Navigate to project folder
cd Quiz-React-App
3. Install dependencies
npm install
4. Start development server
npm start
🧩 How It Works
Questions are loaded from a local data.js file
User selects an option
Correct answer → highlighted in green
Wrong answer → highlighted in red
Score increases for correct answers
After last question, result screen is shown
User can restart the quiz anytime
